KITE

隐私政策

生效日期：2026-11-05 · 包名：app.kite.agent

Kite 是一个运行在 Android 手机上的 AI 智能体。我们尽量让数据留在你的设备上。

我们不收集什么

  • 不要求注册账号。
  • 不收集姓名、手机号、通讯录、位置、设备标识符。
  • 不集成广告 SDK、统计 SDK 或崩溃上报服务。
  • 不把会话、文件、API Key 上传到我们的服务器。

数据保存在哪里

  • 会话记录与工作区文件：应用私有目录。
  • API Key：Android Keystore AES-GCM 加密后保存在本机。
  • 卸载应用会删除上述本机数据。

数据会发给谁

Kite 采用「自带 Key」模式。你填写模型服务的接口地址和 Key，Kite 会把提示词、会话上下文和工具结果发送到你配置的服务商，用于完成请求。这些请求受该服务商的隐私政策约束。

如果接口地址是 http://，流量可能是明文；请自行评估网络风险。

设备权限

  • INTERNET / ACCESS_NETWORK_STATE：调用模型接口、抓取网页。
  • POST_NOTIFICATIONS：任务执行时的前台通知（Android 13+，可选）。
  • FOREGROUND_SERVICE / DATA_SYNC：任务执行期间保活（可选）。

Kite 不申请存储、相机、麦克风、位置、通讯录权限。

Shell 工具

Shell 默认关闭。开启后，模型生成的命令在应用沙盒内通过 /system/bin/sh 执行，工作目录限制在工作区；不获取 root，不访问其他应用私有数据。

个人版说明

Google Play 上架的是 release 版，只申请联网、通知和前台服务权限。

你自己侧载的 personal 版会额外声明相机、麦克风、定位、通讯录、日历、短信、通话记录、电话状态、身体传感器、活动识别、蓝牙、媒体、所有文件访问等权限，并提供 Root / Shizuku Shell 入口。这些权限不会自动生效，必须由你在系统弹窗或设置里逐项同意；Root 需要手机已 root，Shizuku 只是 ADB shell 权限。个人版不建议分发或上传 Google Play。

儿童

Kite 面向 13 岁及以上用户，不面向儿童设计。

删除数据

  • 长按任务可删除单个会话。
  • 系统设置 → 应用 → Kite → 清除数据，或直接卸载。
  • 个人版切到 /sdcard/Kite 后，该目录不会随卸载删除，需要手动清理。
